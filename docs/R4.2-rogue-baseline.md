# R4.2 — Baseline avant modification

Base `5530b8f` (fusion R4.1), arbre propre. Mesures réalisées avant modification du moteur : seed initiale 42, **300 runs par politique**, trois politiques existantes et paramètres inchangés, quatre réussites de survie au maximum. Copie figée des sources pour garder la comparaison indépendante. `npm test` : 143 réussites. CI de la base fusionnée : verte.

La montée du minimum moyen ralentit entre actes 2 et 3. Certaines obligations sont déjà satisfaites par tous les optimums non contraints. Les pools de survie descendent à **deux candidats** : tout mécanisme de variété doit pouvoir se relâcher sans toucher aux règles actives. Une forme remplace chaque chiffre par `n` et conserve l'ordre des opérations ; elle décrit un témoin canonique, pas toutes les façons humaines de résoudre la cible.

Les données détaillées, distributions de chiffres/opérations, cartes et performances sont dans [R4.2-rogue-baseline.json](R4.2-rogue-baseline.json). Les outils reproductibles et les différences finales sont décrits dans le rapport R4.2.
