# Captures R4.3B

Preuves issues du navigateur et de l’émulateur Android, décrites dans le [rapport](../../R4.3B-visual-integration.md). Les noms `before` désignent la base fusionnée avant intégration ; `after` désigne les applications testées pendant ce jalon. Les ressources, étapes et heures changent au fil du parcours : les comparer selon les états documentés, pas comme des puzzles identiques.

- `android-iteration1-active-small.png` : défaut intermédiaire corrigé, conservé pour le journal QA ; ce n’est pas l’interface livrée.
- `android-after-resume-active.png` : preuve de reprise pendant les essais, avant le dernier réglage de fonte/densité.
- `android-after-active.png` : version livrée au format habituel ; `android-after-boss3-active-small.png` : phase finale à 360 × 640 dp.
- `android-after-active-reference-frame.png` : plein écran original 852 × 1990 px, avec barres système. La planche de comparaison recadre seulement ces barres.
- `web-after-active.jpg` et `web-before-active.jpg` : cible 41 à 1672 × 941, comparaison avant/après.
- `qa-*` : planches documentaires (juxtaposition, titres, recadrage ou réduction d’échelle). Les références anciennes y sont identifiées comme telles. Elles ne sont ni de nouveaux assets de jeu ni des captures d’une application simulée.

Les captures brutes sont conservées sans retouche. Certaines images de transitions précèdent le prochain affichage complet ; les géométries finales sont évaluées à partir des captures stables citées dans le [journal QA](../../../design-qa.md). Aucun export de journaux privés, correspondance d’alias ou archive originale n’est inclus.
