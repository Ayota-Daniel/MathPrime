# feat: rendre Rogue V1 jouable dans l'application Web

Le moteur Rogue V1 était accessible uniquement via API et CLI. Ajoute une route Web dédiée reliée au menu : accueil, préparation chronométrée, saisie, indices partiels, cartes, résultats, trois boss, victoire, survie et bilan. Réutilise le contrôleur R2.1 et les composants de saisie/temps existants ; aucun calcul métier n'est réimplémenté dans React et aucune solution témoin n'est affichée automatiquement.

Les transitions sont protégées contre les doubles actions, l'abandon est confirmé et les timers sont nettoyés. Le score reste limité à la session en mémoire, sans sauvegarde/reprise, modification du profil ou leaderboard. Le premier draft reste après deux puzzles, conformément aux règles actuelles. Aucune carte initiale ou modification d'équilibrage n'est introduite.

Validation : 97 tests réussis via `npm test`, typechecks moteur/Web/mobile et build Web réussis. Parcours navigateur complet effectué jusqu'à la victoire en 16 réussites puis défaite en survie, avec victoire conservée ; contrôles à 390 et 320 px et réponse Classique validée. Rapport détaillé : `docs/R3.1-rogue-web.md`. Aucun test humain d'équilibrage ou matériel Android revendiqué.

Base : modernization (PR R2.1 #9 fusionnée). Aucune modification des règles des autres modes, de Supabase ou du classement. Ne pas fusionner automatiquement.
