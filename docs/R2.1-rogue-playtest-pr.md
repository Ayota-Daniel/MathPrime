# feat: playtest terminal interactif du Rogue V1

Le prototype R1 n'était jouable que par API ou agents synthétiques. Ajoute une commande terminal pour qu'une personne puisse préparer, résoudre et terminer une run, choisir ses cartes ou continuer en survie, puis obtenir un JSON local exploitable. Deux formats : un acte avec son boss, ou les trois actes complets.

Le contrôleur conserve l'horloge simulable du moteur et utilise un adaptateur monotone pour l'expiration automatique sans saisie. Les soumissions sont explicites et les erreurs de commande ne coûtent pas de vie. Les indices donnent trois informations partielles distinctes, avec les mêmes ressources et pénalités R1. Les témoins restent cachés avant résultat, y compris dans l'autosave actif. Les journaux restent dans `.playtests/rogue-v1/`, exclu de Git ; aucun envoi réseau ni donnée personnelle demandée.

Validation : 86 tests réussis (R1/R1.1 conservés), typechecks moteur avec adaptateur Node, web et mobile, build web et `git diff --check`. Essais Linux en pseudo-terminal ANSI et en mode dégradé, dont compteur avec saisie partielle, expiration automatique, indice, choix tactique et abandon ; aucun résultat humain d'équilibrage revendiqué. Rapport et commandes : `docs/R2.1-rogue-playtest.md`.

Aucune interface graphique, intégration production, modification de l'équilibrage ou dépendance ajoutée. Les pools étroits et heuristiques R1.1 restent à observer. Ne pas fusionner automatiquement.
